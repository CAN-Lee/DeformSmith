# DeformSmith: Physics Harness-Guided Hierarchical Generation of Deformable Assets for Robot Manipulation

[![Project Page](https://img.shields.io/badge/Project-Page-blue?logo=githubpages)](https://can-lee.github.io/deformsmith-web/)
[![arXiv](https://img.shields.io/badge/arXiv-2609.18620-b31b1b?logo=arxiv)](https://arxiv.org/abs/2609.18620)
![Hugging Face (coming soon)](https://img.shields.io/badge/Hugging_Face-Coming_soon-ffcc4d?logo=huggingface)

![DeformSmith teaser](assets/teaser.jpg)

DeformSmith generates deformable assets from text or a single image, connecting geometry, physical modeling, material behavior, and robot interaction through a shared physics harness.
